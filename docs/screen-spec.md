# Demo Screen Specification

## 画面一覧

| URL / route | 画面 | 目的 | 関連ファイル |
|---|---|---|---|
| `/`（静的な `index.html`） | Timeline Generator Demo | 同じサンプルデータの横型・縦型表示と切り替えを示す | `index.html`, `timeline.js`, `css/timeline.css` |

クライアントルーター、別画面、認証画面、権限別画面はありません。GitHub Pages上の正式な公開URLはリポジトリ内で確認できません。

## 表示項目

- タイトルと説明文
- 「横型」「縦型」切り替えボタン
- タイムライン表示領域
- 操作結果を通知する `aria-live="polite"` のフィードバック領域

横型は年・月ヘッダー、イベント名・アイコン、レーン、接続線、今日マーカーを表示します。縦型は年見出し、日付・時刻、カード見出し、説明、名前、詳細操作を表示します。

## 操作

- 初期状態は横型で、「横型」の `aria-pressed` は `true` です。
- 切り替えボタンは `timeline.setLayout()` を呼び、選択状態、横スクロール設定、フィードバック文を更新します。
- デモはeventモードで、横型イベントまたは縦型の「詳しく見る」を操作すると選択したイベント名をフィードバック領域へ表示します。
- 640px以下では縦型カードを時間軸の右側へまとめ、余白と文字サイズを調整します。

## 状態別表示

| 状態 | 現在の仕様 |
|---|---|
| 通常 | サンプル4件を描画し、横型・縦型を切り替え可能 |
| ローディング | データ取得がないため専用表示なし |
| データなし | 専用メッセージなし。横型は空グリッド、縦型は空リストになる |
| エラー | ユーザー向け表示なし。対象DOMなし等はコンソールへ出力 |
| 権限なし | 認証・権限機能がないため対象外 |

## 使用APIと外部連携

画面は `TimelineGenerator` のコンストラクター、`render()`、`setLayout()` を使用します。HTTP API、DB、外部サービス、環境変数は使用しません。サンプルデータは `index.html` 内に直接定義されています。

## 要確認事項

- 正式な対応ブラウザ、キーボード操作、スクリーンリーダーの受入基準
- データなし・入力不正時にユーザー向け状態表示を追加するか
- デモ内の説明文にある「説明の省略表示を切り替えられる」という記述は、現在の実装（常に全文表示）と矛盾している
