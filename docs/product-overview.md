# Product Overview

## 目的

Timeline Generator は、プロジェクトやイベントの時系列と相互関係をブラウザ上で可視化する軽量な JavaScript ライブラリです。サーバーやビルド工程を必要とせず、既存ページへ JavaScript と CSS を読み込んで利用します。

## 対象ユーザーと利用シナリオ

- プロジェクト、製品、活動履歴などを時系列で紹介するWebページの実装者
- イベント間の関係を横型グリッドで示す
- 出来事を新しい順の縦型カードで読ませる
- コールバックまたは外部リンクで詳細画面へ誘導する

実際の採用組織、利用者属性、業務要件はリポジトリから確認できません。

## 現在の主要機能

- `hour`、`day`、`month`、`quarter`、`year` 単位の列生成
- 横型のヘッダー、レーン、イベント、今日の位置、イベント間接続線
- 長期間の横型表示に対する列単位の仮想スクロール
- 縦型の年見出し、日時、新しい順のカード、レスポンシブ表示
- 同一日時で入力順を維持する安定した表示順
- `setLayout()` による横型・縦型の切り替え
- イベント選択コールバックと外部リンクモード

## 既知の制約

- データは呼び出し元がメモリ上の配列として渡します。永続化、編集画面、HTTP API、DB、認証、権限管理はありません。
- 横型は `start` と `end` の両方が生成列に完全一致しないイベントを描画しません。期間の長さはボックス幅には反映されず、配置は `start` を基準にします。
- 縦型では `links` と `lane` を描画に使いません。
- 入力検証は限定的です。不正値の一部は既定値へフォールバックし、一部はコンソール警告または未描画になります。
- 自動テスト、パッケージ管理、バージョニングされた配布物はありません。
