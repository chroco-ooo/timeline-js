# Testing Policy

## 現在のテスト構成

自動テスト、テストフレームワーク、fixture、mock、lint、format、typecheck、build は設定されていません。DB、外部API、認証、権限も実装されていないため、現時点の対象外です。

確認済みの最小コマンドは次のとおりです。

```powershell
node --check timeline.js
python -m http.server 8000
```

2つ目のコマンドをリポジトリルートで実行し、`http://localhost:8000/` をブラウザで確認します。自動テストがないため、構文確認だけで動作確認済みとは判断しません。

## 主要確認観点

| 対象 | 正常系 | 異常系・境界値 |
|---|---|---|
| 初期描画 | 対象DOMへ描画できる | 対象DOMなし、空の `projects` / `links` |
| scale | `hour` / `day` / `month` / `quarter` / `year` の列とラベル | 月末・年末、うるう日、範囲外、不正日付、開始と終了が同じ |
| 横型 | レーン、今日マーカー、接続線、コールバック、リンク | 存在しないリンク先、範囲外イベント、レーン上下限、長い名前 |
| 縦型 | 新しい順、年見出し、同日時の入力順、説明、画像、詳細操作 | 日付なし・不正日付、画像なし・不正URL、タイトルなし |
| 縦型NOW | 表示期間内、同時刻event直後、横型Todayとの統一 | 開始前、終了後、開始・終了境界、NOW年にeventなし |
| 切り替え | `setLayout()` の往復 | 連続操作、スクロール後の切り替え、イベントリスナー残存 |
| 仮想スクロール | 閾値超過時の表示とスクロール | 閾値ちょうど、先頭・末尾、resize、接続線と今日マーカー |
| レスポンシブ | 640px超と640px以下 | 狭幅、横スクロール、フォーカス可視性 |

## 手動確認

- デモの「横型」「縦型」ボタンと `aria-pressed` が同期すること
- 横型でスクロール、イベント選択、接続線、今日表示が崩れないこと
- 縦型でカードが新しい順になり、詳細ボタンだけがコールバックまたは外部リンクを実行すること
- 縦型で年区切り、実線軸、NOW、画像あり・なしのcardが仕様どおり表示されること
- 641px、640px、639px、320pxで上部サムネイル、余白、横あふれを確認すること
- キーボード操作時にボタン・リンクのフォーカスが見えること
- ブラウザコンソールに想定外のerror / warningがないこと

Issue #3の詳細ケース、デモデータ条件、before / after撮影条件は `docs/specs/3/test-plan.md` に従います。

## 不足箇所

- 日付解析と列生成の単体テスト
- DOM描画、クリック、レイアウト切り替えの統合テスト
- 仮想スクロールとSVG接続線の回帰テスト
- 複数ブラウザ、モバイル、アクセシビリティの自動確認
- CI上の構文確認またはテストゲート

テスト基盤や依存関係の導入は設計判断を伴うため、実装前に保守者へ確認してください。
